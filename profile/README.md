# HelgaWind

HelgaWind — Minecraft-сервер. Здесь ведётся разработка проектов и плагинов для его работы и развития.

Информация о сервере: **[helgawind.ru](https://helgawind.ru)**.

## Ошибки и идеи

Понятное описание помогает быстрее разобраться в проблеме. Сообщая об ошибке, расскажите, что вы делали, что ожидали увидеть и что произошло. Если есть скриншот или текст ошибки, приложите их. Неизвестную версию можно обозначить как «не знаю».

Предлагая улучшение, опишите, кому оно поможет и какую задачу решит. Пример игровой ситуации полезнее, чем только название желаемой функции. Не публикуйте пароли, токены и другие секреты.

## Для команды

- [Рабочий репозиторий HelgaWind HQ](https://github.com/helgawind-mc/helgawind-hq) — контекст, правила работы и задачи.
- [Доска HelgaWind Development](https://github.com/orgs/helgawind-mc/projects/1) — планирование и состояние работы.

Эти разделы доступны участникам с соответствующими правами GitHub.

## Обсуждение задач с ChatGPT

Передайте помощнику ссылку на нужный репозиторий и опишите задачу. Помощник изучает доступные материалы, уточняет требования и показывает черновик issue с критериями приёмки.

Публикация выполняется после явного согласия и при наличии инструмента записи. Если доступ к GitHub ограничен, результатом остаётся готовый текст для публикации командой. Созданная задача подтверждается ссылкой; её приоритет и включение в релиз определяются отдельно.
